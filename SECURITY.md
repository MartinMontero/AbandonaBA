# Seguridad

Reporta problemas de seguridad abriendo un issue en https://github.com/MartinMontero/AbandonaBA/issues, **sin detalles que permitan explotarlos**: pide un canal privado y te contestamos.

Los issues de GitHub **no son anónimos**. No publiques datos personales, documentos de trabajo ni información del banco.

Alcance: el sitio no guarda datos de usuarios. Las preocupaciones principales son: solicitudes a terceros, cookies o almacenamiento no deseados, una cabecera de seguridad faltante, o una cifra legal incorrecta.
